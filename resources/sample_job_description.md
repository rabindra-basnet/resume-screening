# Sample Job Description — Senior Python Engineer

## About the role

We are looking for a Senior Python Engineer to join our platform team. You will
design and build backend services and APIs that power our data products.

## Responsibilities

- Design, build, and maintain REST APIs using FastAPI.
- Work with relational databases and write efficient SQL.
- Integrate third-party APIs and LLM services.
- Build CI/CD pipelines and deploy services to the cloud.
- Mentor junior engineers and lead code reviews.

## Requirements

- 5+ years of professional software engineering experience.
- Strong proficiency in Python and FastAPI (or similar frameworks).
- Experience with PostgreSQL and SQLAlchemy.
- Familiarity with cloud platforms (AWS, GCP, or Azure).
- Understanding of CI/CD and Docker.
- Bonus: experience with LLM integration, OpenAI or Anthropic APIs.

## Nice to have

- Knowledge of the OpenAI API and prompt engineering.
- Experience with Streamlit or other data-application frameworks.
- Exposure to async programming (asyncio).

_Skills summary for screening: Python, FastAPI, SQLAlchemy, PostgreSQL, Docker,
CI/CD, REST APIs, AWS, LLM integration._
